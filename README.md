# Amal & Ahmad — Wedding Invitation

Premium interactive wedding invitation built with React + Vite.

## Image assets

Only three visual assets are used:

- `public/images/opening-cover.jpg` — Opening screen background
- `public/images/first-section-background.jpg` — First section paper background
- `public/images/flower-decoration.png` — Signature botanical motif + favicon

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
